## Abstract
The Blood Bank Inventory and Donor Matcher is a system designed to manage blood bank inventory and donor information and help identify suitable donors based on blood group requirements.

## Setup and Execution
1. Install Java JDK.
2. Open the project in IntelliJ IDEA.
3. Open the files in the `src` folder.
4. Run `Main.java`.
